# Documentação

Este diretório centraliza a metodologia do projeto, a relação das fontes oficiais e o roadmap de evolução.

## Arquivos previstos

- `metodologia.md` — regras de coleta, classificação e checagem de fontes
- `fontes-oficiais.md` — lista de portais e APIs oficiais
- `roadmap.md` — visão de evolução e entregas

## Diretrizes

1. manter rastreabilidade oficial para cada entrada
2. separar documentos de referência de documentos processuais
3. padronizar metadados por tipo de fonte
4. documentar limitações e recortes de cobertura

# Scripts

Este diretório guarda os utilitários para coleta, normalização e exportação dos dados.

## Arquivos planejados

- `fetch_sources.py` — coleta de fontes oficiais
- `normalize_records.py` — padronização dos metadados
- `export_json.py` — exportação em JSON/CSV/Markdown
- `search_index.py` — criação de índices para busca textual

## Objetivo

Padronizar a operação do repositório e evitar que cada dado seja armazenado em formato diferente.

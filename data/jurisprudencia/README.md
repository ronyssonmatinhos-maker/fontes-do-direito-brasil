# Legislação

Este diretório concentra fontes normativas, como:
- leis federais
- leis estaduais
- leis municipais
- constituição
- atos normativos
- regulamentos e atos administrativos

## Objetivo

Manter uma estrutura organizada para a busca e checagem de textos legais, separando-os por esfera e por tipo de normativa.

## Organização sugerida

```text
data/legislacao/
├── federal/
├── estadual/
├── municipal/
├── constitucionais/
├── regulamentos/
└── README.md
```

## Critérios

- manter a origem oficial
- registrar URL e data de coleta
- separar normas vigentes de revogadas
- preferir textos completos quando possível
